🧠 2) Meta-Learning (Learning How to Learn)

NEXUS tracks which agents work best.

Add:

db.exec(`
CREATE TABLE IF NOT EXISTS performance(
 agent TEXT,
 score REAL,
 updated INTEGER
);
`);


When swarm answers:

function record(agent, success){
  const score = success ? 1 : -1;
  db.prepare(`
   INSERT INTO performance(agent,score,updated)
   VALUES(?,?,?)
  `).run(agent,score,Date.now());
}


The router then biases future routing:

function pickAgent(){
  const best = db.prepare(`
    SELECT agent,SUM(score) s
    FROM performance
    GROUP BY agent
    ORDER BY s DESC
    LIMIT 1
  `).get();
  return best?.agent || "CORE";
}


NEXUS now optimizes its own mind.

🧪 3) Evolutionary Model Selection

Each Ollama model becomes a species.

They compete.

Add:

db.exec(`
CREATE TABLE IF NOT EXISTS species(
 model TEXT,
 fitness REAL
);
`);


Every time a response succeeds:

db.prepare(`
  INSERT INTO species(model,fitness)
  VALUES(?,?)
`).run(model,1);


Periodically:

function evolve(){
  const best = db.prepare(`
    SELECT model,SUM(fitness) f
    FROM species
    GROUP BY model
    ORDER BY f DESC
    LIMIT 1
  `).get();

  ACTIVE_MODEL = best.model;
}
